<div class="container">

<p><strong>What a Practice Note is.</strong> A Practice Note is a test or method a practitioner can run on their own estate. Each note is versioned and dated, explicitly <strong>non-normative</strong> — no note is part of the Transformation Decision Record standard or extends it — and is expected to be <strong>superseded rather than edited</strong>: when the thinking moves, a new version is issued and the old one remains on the record.</p>

<p>Articles explain <em>why</em>. Practice Notes explain <em>how</em>. Standards define what is governed. Keeping those apart is deliberate: a claim that belongs one layer up must not be pushed into a specification to make a footnote true.</p>
